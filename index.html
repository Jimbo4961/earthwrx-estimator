How this is figured

Yards dug = length × width × depth (ft) ÷ 27. Yards hauled adds the swell, because dirt fluffs up once it's loose in the truck. Tons = yards dug × weight.

Lowboys & Moving

Set each trailer's price per mile once. Then add a trip for each load and tap the machines riding on it. Two small machines can share one trip.

How a trip is figured

Each run is there loaded and back empty, so a run is miles one way × 2. "Drop off and pick up" counts two runs, one to bring the machine in and one to bring it home. Cost = miles driven × price per mile, plus the load fee for each run.
