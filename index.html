How this is figured

Yards dug = length × width × depth (ft) ÷ 27. Yards hauled adds the swell, because dirt fluffs up once it's loose in the truck. Tons = yards dug × weight.

Lowboys & Moving

Set each trailer's price per mile once. Then add a trip for each load and tap the machines riding on it. Two small machines can share one trip.

How a trip is figured

Each run is there loaded and back empty, so a run is miles one way × 2. "Drop off and pick up" counts two runs, one to bring the machine in and one to bring it home. Cost = miles driven × price per mile, plus the load fee for each run.

Putting it in QuickBooks

One time: tap "QuickBooks items list" and send the file to yourself. In QuickBooks Online: gear (Settings), then Import data, then Products and services. Upload the file. When it asks, match "Income Account" to your income account.

Each invoice: in QuickBooks, + New, then Invoice. Pick the customer. For each line, pick the same item name and type the amount from this invoice. Tick Tax on the same lines this invoice marks with T. QuickBooks adds the sales tax.

To send the customer a copy: tap "Print or save PDF", choose Save as PDF, then text or email the PDF.
